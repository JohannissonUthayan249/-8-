# n8n Workflow: Транскрибация и оценка звонков через Telegram

Автоматический воркфлоу для n8n, который принимает аудиозаписи звонков через Telegram-бота, транскрибирует их с помощью OpenAI Whisper и оценивает качество звонка по заданным критериям с помощью GPT-4o.

## 📋 Схема работы

```
Telegram (аудио) → Проверка файла → Скачивание → OpenAI Whisper (транскрибация)
    → GPT-4o (оценка по критериям) → Telegram (результат)
```

## 🎯 Критерии оценки

| Критерий | Максимальный балл |
|---|---|
| Выявление потребностей | 0–2 балла |
| Презентация | 0–3 балла |
| Работа с возражениями | 0–2 балла |
| Корректность передачи | 0–2 балла |
| Корректная работа с лотами | 0–1 балл |
| Обязательные вопросы | ✅/❌ по каждому |
| Сервис клиенту | 0–10 баллов |
| **Средний балл проверки** | **0–10 баллов** |

## ⚙️ Требования

- **n8n** (версия 1.30+, рекомендуется последняя стабильная) — [установка n8n](https://docs.n8n.io/hosting/)
- **Telegram Bot** — создайте бота через [@BotFather](https://t.me/BotFather)
- **OpenAI API ключ** — получите на [platform.openai.com](https://platform.openai.com/)

## 🚀 Установка и настройка

### 1. Импорт воркфлоу в n8n

1. Откройте n8n
2. Перейдите в **Settings → Import from File**
3. Загрузите файл `n8n_workflow_call_transcription.json`

### 2. Настройка Telegram Bot

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot` и следуйте инструкциям
3. Сохраните полученный **Bot Token**
4. В n8n перейдите в **Credentials** и создайте новый **Telegram API**:
   - Вставьте **Bot Token** в поле `Access Token`

### 3. Настройка OpenAI API

1. Перейдите на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. Создайте новый API ключ
3. В n8n перейдите в **Credentials** и создайте новый **OpenAI API**:
   - Вставьте **API Key** в соответствующее поле

### 4. Привязка учётных данных к нодам

После импорта воркфлоу нужно привязать созданные учётные данные:

1. Откройте каждый нод с надписью `Telegram` и выберите учётные данные Telegram Bot
2. Откройте ноды `OpenAI Whisper: Транскрибация` и `GPT-4o: Оценка звонка` и выберите учётные данные OpenAI

### 5. Активация воркфлоу

1. Нажмите тумблер **Active** в правом верхнем углу воркфлоу
2. Убедитесь, что webhook зарегистрирован (n8n покажет URL для Telegram)

## 📱 Использование

1. Откройте чат с вашим Telegram-ботом
2. Отправьте аудиофайл или голосовое сообщение с записью звонка
3. Бот ответит: `⏳ Получен аудиофайл. Начинаю транскрибацию и анализ звонка...`
4. Через 30–120 секунд (в зависимости от длительности записи) бот пришлёт результат анализа

## 🔧 Описание нодов воркфлоу

| Нод | Описание |
|---|---|
| **Telegram Trigger** | Получает входящие сообщения от Telegram-бота |
| **Проверка наличия аудио** | Проверяет, содержит ли сообщение аудиофайл |
| **Ответ: нет аудио** | Просит пользователя отправить аудиофайл |
| **Уведомление о начале обработки** | Уведомляет о начале транскрибации |
| **Получить информацию о файле** | Получает file_path через Telegram API |
| **Скачать аудиофайл** | Скачивает аудиофайл по ссылке |
| **OpenAI Whisper: Транскрибация** | Транскрибирует аудио в текст (русский язык) |
| **GPT-4o: Оценка звонка** | Анализирует диалог и выставляет оценки |
| **Отправить результат в Telegram** | Отправляет результат оценки пользователю |
| **Ошибка обработки** | Уведомляет при возникновении ошибок |

## 📌 Формула расчёта среднего балла

```
Средний балл = ((Выявление потребностей / 2) + (Презентация / 3) +
  (Работа с возражениями / 2) + (Корректность передачи / 2) +
  (Корректная работа с лотами / 1) + (Сервис клиенту / 10)) / 6 × 10
```

Каждый критерий нормализуется к шкале 0–1, затем рассчитывается среднее и масштабируется до 10.

## 🔒 Безопасность

- Не храните API-ключи в открытом виде — используйте credential-менеджер n8n
- Рекомендуется ограничить доступ к боту через `allowed_updates` или проверку `chat_id`
- Аудиофайлы обрабатываются через API и не сохраняются на сервере

## ❓ Решение проблем

| Проблема | Решение |
|---|---|
| Бот не отвечает | Проверьте, что воркфлоу активирован и webhook зарегистрирован |
| Ошибка транскрибации | Проверьте API-ключ OpenAI и баланс на аккаунте |
| Длинные файлы не обрабатываются | OpenAI Whisper поддерживает файлы до 25 МБ |
| Некорректная оценка | Уточните промпт в ноде GPT-4o под ваш бизнес-процесс |
